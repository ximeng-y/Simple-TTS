# Simple TTS

轻量级 Windows 桌面文本转语音工具。接入小米 MiMo 语音合成 API，支持预置音色、文本描述定制音色与音频样本复刻音色三种用法，界面简单、占用低、解压即用。

## 功能

- **三种模型**
  - `mimo-v2.5-tts`：使用预置精品音色合成，支持唱歌模式
  - `mimo-v2.5-tts-voicedesign`：用一段文字描述定制音色，不需要样本
  - `mimo-v2.5-tts-voiceclone`：上传一段音频样本复刻任意音色
- **风格控制**：可点选的开头风格标签（情绪、语调、方言、人设腔调等）与行内音频标签（叹气、哽咽、笑声等），也可以直接用自然语言写「角色 / 场景 / 指导」导演指令
- **软件内试听**：合成完直接播放，可拖动进度、调音量
- **产物管理**：合成结果先落临时目录并按条数上限自动清理，需要留存的点「保存」拷进保存目录
- **内置自动更新**：检查、下载、校验、替换、重启一条龙，兼容中国大陆网络
- **配置持久化**：设置与 API Key 存在程序目录下，API Key 按当前 Windows 账户加密

## 系统要求

- Windows 10 / 11（64 位）
- 打包版无需安装 Python；源码运行需 Python 3.12

## 使用

### 下载即用

到 [Releases](https://github.com/ximeng-y/Simple-TTS/releases/latest) 下载 `SimpleTTS-*-win64.zip`，解压到任意目录，双击 `SimpleTTS.exe`。

程序的所有数据（配置、合成产物、更新中转文件）都放在解压目录下的 `userdata/`，不写系统用户目录，因此整个文件夹拷贝或删除互不影响。**注意**：解压目录里请不要存放无关文件 —— 更新时会覆盖程序文件。

### 从源码运行

```bash
py -3.12 -m venv .venv
.venv\Scripts\pip install -r requirements-dev.txt
```

然后双击 `启动.bat`（或 `.venv\Scripts\pythonw.exe main.py`）。源码运行模式下不提供自我替换更新，检查更新时只会提示用 `git pull`。

### 首次配置

启动后打开「设置 → API KEY」，填入小米 MiMo 的 API Key。Key 经 Windows DPAPI 按当前登录用户加密后存入 `userdata/settings.json`：换个 Windows 账户或把目录拷到别的机器，Key 都读不出来，需要重填。

## 操作要点

- 顶部下拉切换模型，中间的「风格指令 / 音色描述」与「合成文本」每个模型各存一份草稿，切回来不会互相覆盖
- `Ctrl+Enter` 或 `F5` 开始合成，长文本耗时较长（服务端一次性返回整段音频，不走流式）
- 合成中途关窗会直接放弃这次请求，请求无法中断
- 风格标签写在文本最前面，形如 `(温柔 磁性)正文`；行内标签插在任意位置，形如 `[叹气]`
- 同名文件默认不覆盖也不询问，自动加 `_2`、`_3` 后缀；可在设置里改为逐次弹窗确认
- 临时目录只保留最新若干条（默认 10 条，可设为不限制），保存目录里的文件不受影响

## 自动更新

「帮助 → 检查更新…」可手动检查，设置里可开启启动时自动检查（每天至多一次，失败静默不打扰）。

更新源默认直连 GitHub，同时并发尝试多个 GitHub 加速代理前缀，取最快的一个；下载后按 SHA256 与字节数校验，再解压、重启完成替换。加速代理寿命不定，失效了可在「设置 → 更新」里删掉或换掉，删光就是只走直连。

关于信任边界：SHA256 能挡住下载被截断或被中间设备改坏，但更新清单若本身经第三方代理取得，代理可以连清单带更新包一起换掉。个人工具接受这一边界。

## 数据落盘位置

```
userdata/
  output/         合成产物的临时落脚点，按条数上限先入先出清理
  save/           「保存」拷进来的音频，只增不减（位置可在设置里改）
  update/         更新包的下载与解压中转目录，每次启动清空
  settings.json   配置，没改过设置就不存在
```
